Información sobre el dataset
- **Nombre del dataset**: emociones2
- **Descripción**: Dataset de imágenes de rostros con 5 emociones básicas: angry, fearful, happy, sad, surprised
- **Número de instancias**: 200
- **Número de clases**: 5

Se selecciona un 80% de las imágenes para entrenamiento y un 20% para evaluación.
Para la validación durante el entrenamiento se utiliza un 20% de las imágenes de entrenamiento.

La carpeta test será utilizada para la evaluación del modelo.
